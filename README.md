# Stroke-Prediction-Deep-Learning

ANN classifier predicting stroke risk from patient health data, addressing severe class imbalance with SMOTE oversampling.

## Features
- Dense + BatchNormalization + Dropout architecture
- SMOTE oversampling for class imbalance
- StandardScaler normalization and one-hot encoding for categorical features
- EarlyStopping-based training with precision/recall/F1 evaluation for a healthcare-critical task

## Tech Stack
TensorFlow/Keras, imbalanced-learn (SMOTE), Scikit-learn, Pandas

## Setup & Run
1. `pip install -r requirements.txt`
2. Place the stroke dataset CSV in `/data`.
3. Run `python train.py` to preprocess, balance, train, and evaluate the model.
